# 全局规则索引 (Global Rules Index)

> **【强约束指令】**
> 本配置支持跨设备单目录双向同步。
> AI 助手在每次处理任务（尤其是涉及代码修改、代码审查、构建、排版及技能创建时），**必须主动读取并严格遵守** `~/.gemini/config/rules/` 目录下的所有 `.md` 规则文件：
> 1. **`git_rules.md`**: 代码修改后必须自动进行代码审查并执行 Git 自动提交与推送。
> 2. **`skill_sync_rules.md`**: 凡新建/变更技能或规则，必须自动同步更新 `ms-util` 登记簿并自动 Git 提交推送。
> 3. **`typography_rules.md`**: 中文与数字/英文无空格，全英文标点。
> 4. **`temp_script_rules.md`**: 临时文件用完即清。
> 5. **`build_rules.md`**: 除非用户明确要求，否则免自动打包构建。
